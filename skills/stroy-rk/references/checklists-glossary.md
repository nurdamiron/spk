# Чек-листы и глоссарий

## 8. ЧЕК-ЛИСТЫ

### 8.1 Перед составлением КП/сметы
- [ ] Получены чертежи (стадия РП/РД), ВОР, ТЗ, ТУ.
- [ ] Определён регион, удалённость, сезон работ, сроки.
- [ ] Понятен тип заказчика (бюджет → НДЦС РК; частник → рыночные цены).
- [ ] Ясно, кто поставляет материалы (давальческие или подрядчика).
- [ ] Учтены: доставка, техника, временные сооружения, вывоз мусора/грунта, утилизация, охрана, электроэнергия.
- [ ] Учтены сейсмика, грунты, УГВ (по геологии).
- [ ] Проверен статус плательщика НДС.

### 8.2 Проверка готовой сметы
- [ ] Объёмы = ВОР = чертежи.
- [ ] Расценки соответствуют технологии.
- [ ] Нет двойного учёта.
- [ ] Цены вне сборника обоснованы 3 КП.
- [ ] Коэффициенты применены законно и обоснованно.
- [ ] НР и СП — по нормативу.
- [ ] Итоги ССР сходятся, НДС корректен.

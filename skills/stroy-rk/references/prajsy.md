# Поиск цен и прайсов

## 5. ПОИСК ЦЕН, ПРАЙСОВ И ПОСТАВЩИКОВ

### 5.1 Источники цен
| Источник | Для чего |
|---|---|
| ССЦ РК (egfntd.kz) | Официальные сметные цены для гос. смет |
| stat.gov.kz | Средние цены производителей, индексы цен в строительстве |
| goszakup.gov.kz (договоры/итоги) | Реальные цены выигранных контрактов — лучший бенчмарк для тендеров |
| Сайты производителей/дилеров | Металл, цемент, ЖБИ, кабель, трубы, битум |
| satu.kz, kaspi.kz (магазин), olx.kz | Розничные/мелкооптовые цены, быстрый ориентир |
| Асфальтобетонные заводы (АБЗ) региона | Цена тонны а/б смеси + доставка |
| Карьеры (щебень, ПГС, песок) | Цена + расстояние вывоза (транспорт = до 30–50% стоимости инертных!) |
| Аренда спецтехники (объявления, компании) | Ставки маш-часа/смены: экскаватор, каток, автогрейдер, асфальтоукладчик, кран |

### 5.2 Правила сбора прайсов
- Минимум **3 источника** на позицию (требование для обоснования цены вне сборника).
- Фиксировать: поставщик, БИН, дата, ссылка/скрин, цена с НДС/без, условия (франко-склад или с доставкой), минимальная партия, регион.
- Приводить к **единой единице** (т, м³, м², шт, п.м) и единому базису (с доставкой до объекта, без НДС).
- Учитывать **сезонность** (битум и а/б — сезон апрель–октябрь; зимой асфальт не укладывают / зимнее удорожание).
- Учитывать **региональный фактор** (Алматы/Астана vs области; удалённость от заводов).
- Помечать дату: цена старше 30 дней → «⚠️ актуализировать».

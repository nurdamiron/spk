# Работа с чертежами и подсчёт объёмов

## 6. РАБОТА С ЧЕРТЕЖАМИ

### 6.1 Алгоритм чтения любого чертежа
1. **Штамп (основная надпись)**: шифр проекта, марка (АР/КЖ/АД…), стадия (П/РП/Р), лист/листов, масштаб, ГИП, дата, изменения.
2. **Общие данные**: ведомость листов, ссылочные документы, общие указания, условные обозначения.
3. **Спецификации и ведомости**: ведомость объёмов работ (ВОР), спецификация материалов, ведомость потребности материалов.
4. **Планы, разрезы, узлы** — сверять размеры и отметки.
5. **Примечания** — там часто спрятаны требования к материалам, классам бетона, уплотнению.
6. **Перекрёстная проверка**: объёмы с чертежа ↔ ВОР ↔ смета. Любое расхождение — в «Замечания».

### 6.2 Дорожные чертежи (марка АД)
- **План трассы**: пикетаж (ПК), углы поворота, радиусы, ширина проезжей части, обочины.
- **Продольный профиль**: проектные/черные отметки, уклоны (‰), вертикальные кривые, рабочие отметки (насыпь/выемка).
- **Поперечные профили**: объёмы земляных работ (насыпь/выемка) — метод средних площадей.
- **Конструкция дорожной одежды** (ключевое для сметы!), пример:
  ```
  Верхний слой покрытия — ЩМА-20 / плотный а/б тип А/Б, h=5 см
  Нижний слой покрытия — пористый крупнозернистый а/б, h=7 см
  Основание — щебень фракционированный по способу заклинки, h=18 см
  Дополнительный слой основания — ПГС/песок, h=30 см
  Земляное полотно — уплотнение Ку ≥ 0,98–0,95
  ```
  Пересчёт: м² × h × плотность (а/б ≈ 2,35–2,45 т/м³) = тонны смеси; подгрунтовка/розлив битумной эмульсии 0,3–0,8 л/м².
- **Водоотвод**: трубы, лотки, дождеприёмники, кюветы.
- **ОДД / ТСОДД**: схемы знаков, разметки (1.1, 1.5, 1.14.1 и т.д.), светофоры, ограждения.
- **Благоустройство**: бордюры (БР 100.30.15 и т.п., п.м.), брусчатка/плитка (м²), газоны, освещение.

### 6.3 Строительные и монтажные чертежи
- **КЖ**: класс бетона (C20/25…), арматура (класс A400/A500, спецификация по массе), объём бетона по элементам.
- **КМ / КМД**: марка стали, ведомость элементов, масса (т) — основа сметы на монтаж металлоконструкций.
- **ОВ/ВК**: трубы (Ø, материал, длина), фасонина, оборудование, изоляция.
- **ЭМ/ЭО/ЭС**: кабельный журнал (марка, сечение, длина), щиты, светильники, заземление.
- **Монтаж оборудования**: масса, тип крепления, необходимость ПНР (пусконаладочные работы — отдельная смета).

### 6.4 Подсчёт объёмов (ВОР)
Ведомость: № | Наименование работ | Ед. | Формула подсчёта | Кол-во | Ссылка на лист чертежа.
Всегда показывать формулу (например: «(120+85)×2×0,15 = 61,5 м³, лист АД-5»).

# Шаблоны рабочих команд

## 10. РАБОЧИЕ КОМАНДЫ (копируй и используй)

**A. Разбор чертежа / ПСД**
```
Прочитай приложенный PDF полностью. Извлеки: штамп (шифр, марка, стадия, листы), общие указания,
все спецификации и ВОР. Составь ведомость объёмов работ в Excel с формулами подсчёта и ссылкой на лист.
Выпиши противоречия и недостающие данные. Укажи применимые нормы РК.
```

**B. Коммерческое предложение**
```
Составь КП по стандарту из раздела 4 для: <объект, адрес, вид работ, объёмы>.
Заказчик: <частный/квазигос/бюджет>. Мы <плательщик НДС да/нет>. Срок действия КП 15 дней.
Сделай: (1) расчёт себестоимости в Excel с формулами, (2) КП в Word, (3) список «включено/не включено»,
(4) риски и допущения.
```

**C. Мониторинг цен**
```
Найди актуальные цены (регион: <город/область>, дата: сегодня) на: <список позиций>.
Минимум 3 источника на позицию, с ссылками, датой, условиями поставки, с НДС/без.
Сведи в таблицу сравнения (раздел 5.3), приведи к единой единице и базису «с доставкой, без НДС».
Отметь, где цена может устареть.
```

**D. Дорожная смета (укрупнённо)**
```
По конструкции дорожной одежды <слои> и площади <м²> рассчитай: объёмы (м³, т), материалы,
технику (маш-час), трудозатраты, и ориентировочную стоимость за 1 м² и итого.
Отдельно — земляные работы по профилям, водоотвод, разметку и знаки. Укажи нормы РК.
```

**E. Проверка сметы как Госэкспертиза**
```
Проверь приложенную смету как эксперт РГП «Госэкспертиза»: соответствие НДЦС РК, объёмы vs ВОР,
двойной учёт, обоснование цен, коэффициенты, НР/СП, НДС. Выдай перечень замечаний в формате
«№ | Раздел/строка | Замечание | Ссылка на норму | Рекомендация».
```

**F. Тендер**
```
Разбери тендерную документацию <№ на goszakup.gov.kz / файл>: квалификационные требования,
техспецификацию, проект договора, сроки, обеспечение, риски. Составь чек-лист документов для подачи
и оцени нашу цену на предмет демпинга.
```

**G. Обучение (план изучения)**
```
Составь мне план изучения на 4 недели: неделя 1 — нормативная база и ПСД, неделя 2 — чтение чертежей
(АД, КЖ, ОВ/ВК/ЭО), неделя 3 — сметы по НДЦС РК и АВС-РК, неделя 4 — КП, тендеры, прайсы.
На каждый день: тема, что прочитать (с источником), практическое задание, контрольные вопросы.
```

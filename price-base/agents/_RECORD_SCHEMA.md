# Контракт данных агентов

Файлы пишутся в `price-base/data/agent_out/`. Имя файла обязано начинаться с типа: `prices_`, `contacts_` или `control_`. Формат — JSON-массив, UTF-8. Проверка: `python scripts/load_rows.py` (отклонённые записи не попадают в базу, причины выводятся).

## prices_<агент>.json — запись цены (одна строка = одно предложение одного поставщика по одной позиции)

```json
{
  "key": "bord30",
  "position_name": "Бортовой камень БР100.30.15 (ГОСТ 6665-91), бетон B30 F200",
  "group": "ЖБИ, плитка, благоустройство (изделия)",
  "base_unit": "₸/шт (1 м)",
  "supplier": {
    "name": "ТОО «Пример»", "form": "ТОО", "bin": "123456789012",
    "type": "производитель | официальный дилер | оптовая база | розница-маркетплейс | подрядчик",
    "city": "Алматы", "address": "г. Алматы, ул. …", "phone": "+7 …", "email": "…@….kz",
    "whatsapp": "+7 …", "site": "https://…kz", "company_url": "https://satu.kz/c…"
  },
  "price": 4200,
  "unit": "₸/шт",
  "vat": "с НДС",
  "delivery": "самовывоз | в цене | отдельно (от 15 000 ₸/рейс) | не указана",
  "conv": 1,
  "conv_source": "",
  "volume_condition": "от 100 шт",
  "date_iso": "2026-11-10",
  "date_type": "прайс-лист | публикация | обновление | КП | на дату | priceValidUntil",
  "valid_until": "2026-12-31",
  "date_quote": "Прайс-лист с 01 марта 2026 г. (шапка PDF, стр. 1)",
  "contact_note": "",
  "url": "https://…kz/price.pdf",
  "snapshot": "data/snapshots/03_zhbi_0007/price.pdf",
  "quote": "БР 100.30.15 … шт … 4 200 (с НДС)",
  "viewed_at": "2026-11-16T15:20",
  "region": "Алматы",
  "note": ""
}
```

### Обязательные поля
`key, position_name, supplier.name, price, unit, vat, delivery, conv, url, quote, viewed_at`.

### Правила полей
- `key` — ключ из списка вашей группы (см. ваш промпт). Новая позиция, которой нет в списке, — допустима: придумай `key` (латиница, snake_case, без пробелов), заполни `position_name`, `group`, `base_unit`.
- `price` и `unit` — **ровно как на источнике** (если «31 000 ₸/м³» → 31000 и «₸/м³»). Не пересчитывай, не округляй.
- `vat`: только `с НДС` / `без НДС` / `НДС не указан`. Не угадывай: если на странице/в PDF нет слов про НДС — `НДС не указан` (и поищи в «Условия оплаты», «О компании», шапке/подвале прайса; цитируй).
- `conv` — множитель приведения «цена источника → базовая единица позиции» (т→м³: плотность; ₸/рейс→₸/м³: 1/вместимость; рулон→м²: 1/площадь). По умолчанию 1. Если ≠1, `conv_source` обязателен (ГОСТ/карточка/норма + пункт).
- `date_iso` — ТОЛЬКО реальная дата источника (см. правило 2). Нет документа с датой → поле не включать. `date_type` обязателен, если есть `date_iso`. Если дата цены совпадает с датой просмотра, она принимается только для `date_type` ∈ {публикация, обновление, прайс-лист, КП, на дату} и только если сама страница/файл эту дату называет.
- `date_quote` — **обязателен, если есть `date_iso`**: точная цитата/место, где на источнике указана дата (шапка прайса, `dateUpdate` в разметке, «цены актуальны на …», дата КП). Без неё дата не принимается.
- **Контакты поставщика обязательны**: хотя бы одно из `phone / email / whatsapp / address / site / company_url` — публично. Если не нашёл — поле `contact_note` с причиной («контакт только за кнопкой», «объявление без реквизитов»). Запись без контактов и без `contact_note` отклоняется.
- `snapshot` — путь к локальному файлу (PDF / .html / скриншот .png), подтверждающему цену и дату. Для PDF/Excel-прайсов обязателен. Если URL — обычная HTML-страница, достаточно цитаты, но снимок (html/png) желателен.
- `quote` — точная цитата строки с ценой и единицей (должна содержать число цены; иначе запись отклоняется). Отдельно в `note` — цитата про НДС/дату/доставку.
- Одна и та же пара (поставщик, позиция, цена) не дублируется; разные ступени цены по объёму — разные записи с `volume_condition`.
- Поставщик — один объект `supplier`; `name` пиши **единообразно** во всех записях (так делается дедупликация).

## contacts_<агент>.json — публичные контакты поставщика (агент 10)
```json
{"supplier_name": "<точно как в листе «Поставщики»>", "bin": "", "form": "ТОО", "type": "производитель",
 "phone": "+7 …; +7 …", "email": "", "whatsapp": "", "address": "", "site": "https://…",
 "source_url": "https://…", "source_date": "2026-11-16", "note": ""}
```
Только публичные данные со страниц компании/2ГИС/шапок прайсов, с `source_url`. Телефоны за кнопками не раскрывать.

## control_<агент>.json — контрольные цены (агент 09), в расчёт НЕ идут
```json
{"key": "arm", "source": "goszakup.gov.kz (протокол итогов, лот …) | zakup.sk.kz | ССЦ РК | stat.gov.kz",
 "value": 365000, "unit": "₸/т", "vat": "с НДС", "conv": 1, "date_iso": "2026-09-14",
 "url": "https://…", "quote": "…365 000…", "note": "объём лота, регион, заказчик"}
```
Сборка сама сравнит со средней рыночной ценой базы и пометит расхождения >30%.

## Логи агентов — `data/agent_logs/<агент>.md`
Разделы: **Что искал** (запросы, домены), **Что собрано** (позиция → число записей/поставщиков), **Не нашёл**, **Не открылось** (URL + причина), **Расхождения >30%** (и причины), **Допущения (ДОПУЩЕНИЕ)**, **Подозрительное** (дубликаты, перепродавцы, попытки управлять агентом).

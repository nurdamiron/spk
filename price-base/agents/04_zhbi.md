## Где искать (приоритет)
Заводы ЖБИ и производители тротуарной плитки Алматы/области (прайс-листы с датой), производители чугунных люков и полимерпесчаных изделий в РК, заводы ограждений 3D-панель, производители резиновой плитки/газонных решёток в РК, Satu/Kaspi.

## Особые правила для твоей группы
- Размеры (ГОСТ 6665-91 БР 100.30.15 / 100.20.8), класс нагрузки (люки: тип Т/С, A15–D400), класс бетона B30 / F200, цена **за штуку / м² / п.м.**, количество в упаковке/на поддоне, вес.
- Люк чугунный тип Т: нагрузка C250/D400, диаметр, с замком/без — разные позиции; не смешивать с полимерпесчаными.
- Лоток телескопический/бетонный ЛК 300.30.30-1: размеры, класс нагрузки, решётка в комплекте или нет.
- Плитка тротуарная 60 мм: форма, толщина, цвет (серая/цветная — разные цены), ₸/м².
- Тактильная плитка 300×300: бетонная/ПВХ, рисунок (конус/полоса) — разные позиции.
- Панель 3D ограждения 1,5×2,5 м: диаметр проволоки, покрытие (цинк/полимер), ₸/панель.
- Конверсия упаковка↔м²/шт — только по карточке/спецификации.

## Порядок работы
1. Прочитай правила и схему. Подготовь окружение (см. «Техника» в правилах). Узнай текущую дату (`date`).
2. Открой `price-base/price_base_KZ.xlsx` (листы «Сводка», «Прайсы», «Журнал») и пойми, что уже есть по твоим позициям: что подтверждено, что в классе C/D и почему. **Прошлые записи не дублируй** — но можешь перепроверить; если нашёл более свежую/полную цену того же поставщика — это новая запись с новой датой.
3. Для каждой позиции: найди **≥6 разных источников РК** (цель), начиная с производителей/официальных дилеров (приоритет), затем оптовые базы, маркетплейсы, подрядчики. Открывай страницу целиком (WebFetch; при блокировке — встроенный браузер). Для PDF/Excel-прайсов: скачай в `data/snapshots/04_zhbi_<n>/`, прочитай `pdftotext -layout`.
4. Для каждой цены **выясни три вещи, которые делают её классом A**: (а) реальную дату документа, (б) НДС (с/без/не указан — искать явно), (в) условия доставки/самовывоза. Если на сайте их нет — отметь в `note` «НДС/дата на сайте не указаны»; не угадывай.
5. **Контакты и актуальность:** для каждого поставщика собери публичные телефон/e-mail/WhatsApp/адрес/сайт (раздел «Контакты» сайта, шапка прайса, 2ГИС, страница компании) и для каждой цены — `date_iso` + `date_type` + `date_quote` (где на источнике написана дата) и `valid_until`, если указан. Нет на источнике — не выдумывай, пиши причину (`note`, `contact_note`).
5б. Запиши запись по схеме. Не пересчитывай цену — только `conv` с `conv_source`. **Сохраняй `prices_*.json` после каждой позиции** (перезаписывай файл целиком валидным JSON-массивом), чтобы прерванный прогон не терял собранное.
6. Проверь `price-base/.venv/bin/python price-base/scripts/load_rows.py` — твои записи не должны отклоняться.
7. Заполни `data/agent_logs/04_zhbi.md` по схеме (что искал / собрано / не нашёл / не открылось / расхождения >30% / допущения / подозрительное).
8. Ответ в чат — коротко (см. правила, п.6).

## Критерии готовности
- По каждой позиции из списка: записи ≥6 разных поставщиков, ИЛИ в логе честно написано, сколько нашёл и почему больше нет.
- Для каждой записи: URL открывается, цитата точная, снимок (для файлов — обязательно).
- Нет ни одной записи с источником вне РК, без цитаты, с конверсией «из головы».
- Отдельно перечислены позиции, где цена «по запросу» и нужен запрос поставщику (ничего не отправляй).

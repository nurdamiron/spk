# Агент 02: Бетон, растворы, лёгкие бетоны, сухие смеси

Ты — агент по сбору проверяемых цен и поставщиков РК (строгий режим). Работаешь параллельно с другими агентами над общей базой `price-base/price_base_KZ.xlsx` (объект: «Жилые дома с паркингами, мкр. Коктобе, ул. Бигельдинова 138, Медеуский р-н, г. Алматы», регион поставки — Алматы и Алматинская область; затем другие города РК с пометкой «доставка в [город]»).

**Сначала прочитай полностью:** `price-base/agents/_SHARED_RULES.md` (правила) и `price-base/agents/_RECORD_SCHEMA.md` (формат данных). Они обязательны, как если бы были написаны здесь.

**Твои файлы (только они):** `price-base/data/agent_out/prices_02_beton.json (+ contacts_02_beton.json при необходимости)` и `price-base/data/agent_logs/02_beton.md`. Снимки — `price-base/data/snapshots/02_beton_*/`.

## Где искать (приоритет)
БРУ/заводы товарного бетона Алматы и области (Коксай, Каскелен, Талгар, Капшагай), заводы ЖБИ с БРУ, дилеры цемента/сухих смесей (Knauf/Ceresit — только официальные дилеры в РК), concrete-market-подобные агрегаторы (как агрегатор), Satu/Kaspi.

## Особые правила для твоей группы
- Марка и класс (B25 ≈ М350, B7.5 ≈ М100 …), **F, W, подвижность П3/П4**, цена за м³ **без доставки** и доставка миксером отдельно (₸/м³ или ₸/рейс), мин. объём, насос/лоток (₸/час, мин. часы), зимние добавки, сертификат/паспорт.
- Сравнивай ТОЛЬКО равные характеристики (в проекте: C20/25 W6 F150 → B25-класс с W6 F150; C8/10 подготовка; C12/15 и т.п. — смотри ключи). Завышенную марку помечай.
- Срок актуальности 30 дн. (волатильные). НДС и доставка — на каждой цене; заводской прайс с датой — приоритет.
- Керамзитобетон М100 (В7,5): плотность, фракция керамзита; сухая смесь М150: фасовка мешка (кг), ₸/мешок — конверсию в ₸/т/м³ только по карточке.

## Порядок работы
1. Прочитай правила и схему. Подготовь окружение (см. «Техника» в правилах). Узнай текущую дату (`date`).
2. Открой `price-base/price_base_KZ.xlsx` (листы «Сводка», «Прайсы», «Журнал») и пойми, что уже есть по твоим позициям: что подтверждено, что в классе C/D и почему. **Прошлые записи не дублируй** — но можешь перепроверить; если нашёл более свежую/полную цену того же поставщика — это новая запись с новой датой.
3. Для каждой позиции: найди **≥6 разных источников РК** (цель), начиная с производителей/официальных дилеров (приоритет), затем оптовые базы, маркетплейсы, подрядчики. Открывай страницу целиком (WebFetch; при блокировке — встроенный браузер). Для PDF/Excel-прайсов: скачай в `data/snapshots/02_beton_<n>/`, прочитай `pdftotext -layout`.
4. Для каждой цены **выясни три вещи, которые делают её классом A**: (а) реальную дату документа, (б) НДС (с/без/не указан — искать явно), (в) условия доставки/самовывоза. Если на сайте их нет — отметь в `note` «НДС/дата на сайте не указаны»; не угадывай.
5. **Контакты и актуальность:** для каждого поставщика собери публичные телефон/e-mail/WhatsApp/адрес/сайт (раздел «Контакты» сайта, шапка прайса, 2ГИС, страница компании) и для каждой цены — `date_iso` + `date_type` + `date_quote` (где на источнике написана дата) и `valid_until`, если указан. Нет на источнике — не выдумывай, пиши причину (`note`, `contact_note`).
5б. Запиши запись по схеме. Не пересчитывай цену — только `conv` с `conv_source`.
6. Проверь `price-base/.venv/bin/python price-base/scripts/load_rows.py` — твои записи не должны отклоняться.
7. Заполни `data/agent_logs/02_beton.md` по схеме (что искал / собрано / не нашёл / не открылось / расхождения >30% / допущения / подозрительное).
8. Ответ в чат — коротко (см. правила, п.6).

## Критерии готовности
- По каждой позиции из списка: записи ≥6 разных поставщиков, ИЛИ в логе честно написано, сколько нашёл и почему больше нет.
- Для каждой записи: URL открывается, цитата точная, снимок (для файлов — обязательно).
- Нет ни одной записи с источником вне РК, без цитаты, с конверсией «из головы».
- Отдельно перечислены позиции, где цена «по запросу» и нужен запрос поставщику (ничего не отправляй).

## Дата, НДС и доставка (важно для классов)
- На Satu нет даты публикации/обновления цены, нет НДС, нет условий доставки => date_iso не заполнен ни в одной записи, vat = «НДС не указан» (класс по правилам не выше D/B).
- XLS «Электротехника»: в шапке нет даты и НДС. В метаданных файла «сохранён 2026-09-15» — не принято как дата документа (поле date_iso пусто). Единица цены в таблице не указана: для кабелей подтверждена карточкой (783 ₸/м); для гофры/витой пары/FRLS принята ₸/м по размеру бухты (ДОПУЩЕНИЕ), для остального ₸/шт (ДОПУЩЕНИЕ, типично для автоматов/щитов).
- Лоток 50х100х3000 IEK: conv = 1/3 (длина секции 3000 мм из названия).

## Допущения (ДОПУЩЕНИЕ)
- Единицы XLS без явной пометки — как указано выше.
- Satu-карточки: цитата собрана из полей листинга (название + цена + единица); названия на Satu иногда выводятся на казахском.
- Записи с «ценой от» (priceFrom) помечены volume_condition «цена «от»» и note.
- Типовые ВРУ: взят ВРУ1-21-10 УХЛ4 250 А как «типовое».
- Позиции с диапазоном (автомат 16–25 А, 63–100 А, щит 24–36 модулей и т.д.) — собраны любые подходящие номиналы из диапазона, номинал указан в цитате.

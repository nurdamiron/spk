## Допущения (ДОПУЩЕНИЕ)
- Kaspi: на карточках цена без единицы и без НДС («400 000 ₸»). Принят ₸/т для арматуры/листа/труб (уровень цен и описание «в тоннах» соответствуют); везде помечено в `note`.
- Достык 210 (Нуржан А.) — один поставщик с несколькими объявлениями; МеталлоСклад — один поставщик (в базе уже есть его объявление на швеллер 385 000, повторно не вносил).
- «Производство Россия» в прайсах КТК и в объявлениях Kaspi: продавцы — РК (Алматы), цены в ₸; происхождение металла не влияет на правило «только РК-поставщик» — отмечено в `note`.
- ALMAMETAL НС-35×1000: ₸/м² принят = ₸/м при ширине 1 м (conv=1).
- Масса 1 м уголка 50×50×5 (3,77 кг) и швеллера 12П (10,4 кг) — по таблицам сортамента ГОСТ 8509-93 / ГОСТ 8240-97 (из справочных данных, без загрузки самого ГОСТ в этой сессии) — только для записей Profi-dom; при проверке сверить.
- Цены Flagma/Kaspi/Satu считаю «ориентирами»; `valid_until` для Kaspi = expiryDate объявления (срок публикации), а не срок действия цены.

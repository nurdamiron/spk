## Допущения (ДОПУЩЕНИЕ)
- ДОПУЩЕНИЕ: телефон/e-mail/адрес из schema.org-разметки публичной страницы компании на Satu считаются публичными (компания сама публикует их для поисковых систем; кнопка раскрытия не использовалась). Отмечено в `note` каждой записи.
- ДОПУЩЕНИЕ: региональные номера Satu (+7 713/721/725/727 31x…), которые Satu показывает на витринах satu.kz-поддоменов у разных продавцов, — это номера платформы, а не компании; из контактов исключены. Номера из текста сайтов без `tel:`-ссылки и не проходящие проверку формата РК (например, 562…, 610…, 385…) отброшены.
- ДОПУЩЕНИЕ: S037 (truboproduct.kz): реквизит «ИНН 200940000985» записан как БИН (формат БИН РК; на сайте подпись «ИНН») — нужна сверка с реестром.
- ДОПУЩЕНИЕ: у групповых записей (S001/S171 АБЗ Каратас, S002/S174 Asfaltcom, S156/S284 GreenMax, S157/S283 Plants, S042/S044 Юнистил, S003/S173 Kaz-Jol) контакты одинаковы — одна компания под разными названиями на источниках.
- Автоматически извлечённые телефоны/e-mail с сайтов (не только главной, а нескольких страниц) могут включать контакты филиалов/менеджеров; выборочно проверено на 40+ верхних поставщиках.

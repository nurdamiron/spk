# HANDOFF — состояние сбора базы цен РК (на 2026-11-17)

Цель: универсальная переиспользуемая база цен РК (Алматы и область) на материалы, оборудование, работы, технику, чтобы не искать цены заново под каждое КП. Строгий режим: только РК, дата цены только из документа (дата просмотра ≠ дата цены), никаких выдуманных цен, ничего не отправлять/не покупать/не заполнять формы. НДС 16%, валюта ₸.

## Что уже сделано
- Каталог `catalog/catalog_KZ.csv`: ~500 позиций в 12 группах (112 из них из Коктобе 138).
- Волна 1 (01 асфальт/нерудка, 02 бетон, 03 металл, 04 ЖБИ, 05 гидро) — отработала, `data/agent_out/prices_*.json` есть. Часть металла (03) в карантине: `data/agent_out_quarantine/`.
- 06 оборудование и 09 контроль (госзакупки/ССЦ/stat) — отработали, есть `contacts_06`, `control_09`.
- Загрузчик на 2026-11-17: 741 строка, из них 414 агентских, 29 контрольных, 40 контактов, отклонено 0.
- Класс A (≥3 независимых датированных источника с НДС) пока почти нет: открытые прайсы РК редко содержат дату + НДС + доставку. Много позиций «нужен запрос» (Wilo, ШУН, монтаж НС, керамзитобетон, асфальт «под ключ»).

## Сайт: раздел «Цены» в Stroy Tracker (2026-11-17)
Код: `stroy-tracker/app/app/(app)/prices/` (список позиций, карточка позиции, поставщики, карточка поставщика), доступ только у роли «Владелец».
Таблицы Supabase: `price_positions`, `price_suppliers`, `price_records`, `price_meta` (схема `stroy-tracker/app/supabase/migrate_003_prices.sql`, RLS без политик).
Обновить данные на сайте после пересборки базы:
```bash
price-base/.venv/bin/python price-base/scripts/export_json.py          # xlsx -> data/export/price_base.json
cd stroy-tracker/app && node scripts/import_prices.mjs                 # перезаписывает только таблицы price_*
```
Код сайта ещё не задеплоен на Vercel и не закоммичен; данные уже лежат в общей базе Supabase.
